# Role 5: Quantum Control Software Engineer

## What the role does

Writes the software that turns gate and experiment descriptions into pulses on real hardware. Works on pulse sequencing, waveform generation, FPGA firmware interfaces, real-time feedback, and the APIs that users and calibration tools call.

Typical employers are control-electronics companies such as Quantum Machines (its job posting for a cryogenic control electronics developer is in the search results) and Qblox, along with QPU vendors. This is a good fit if you enjoy low-level systems work and real-time constraints.

## Physics depth required: Working to Deep (pulses and control)

You need to understand how a pulse changes a qubit state, how timing and bandwidth limit control, and what optimal control means in practice.
