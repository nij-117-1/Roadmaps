# Role 2: Materials

## Free: quantum programming
- IBM Quantum Learning: *Introduction to quantum computing with Qiskit* (openHPI, free)
- IBM Quantum Learning: *Variational Algorithm Design* (about 8 hours)
- IBM Quantum Learning: *Quantum Diagonalization Algorithms* and *Integrating Quantum and High-Performance Computing*
- Qiskit tutorials and documentation: docs.quantum.ibm.com

## Free: CUDA-Q
- CUDA-Q documentation: nvidia.github.io/cuda-quantum (applications, MPI plugin, multi-GPU platforms, Realtime)
- CUDA-Q Academic: github.com/NVIDIA/cuda-q-academic (hybrid workflows, simulation, dynamics, QEC)
- CUDA-Q release notes (track new features such as PTSBE and Realtime)

## Free: physics for software engineers
- Nielsen & Chuang, Chapters 1–4 (free solutions exist online; use after attempting problems)
- Preskill's Caltech Ph219 notes (free PDF)
- MIT OCW 8.05 (Zwiebach) for the formalism, if you need depth

## Free: HPC workflow engineering
- Slurm documentation (job dependencies, arrays, REST API)
- Apptainer documentation
- Prometheus, Grafana, and OpenTelemetry documentation

## Free: programming references
- Python documentation and NumPy and SciPy reference
- NVIDIA Nsight Systems and Nsight Compute user guides
- C++ reference for CUDA-Q C++ kernels
