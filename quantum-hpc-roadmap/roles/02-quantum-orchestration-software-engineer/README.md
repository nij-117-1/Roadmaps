# Role 2: Quantum–HPC Orchestration Software Engineer

## What the role does

Builds the software that connects HPC schedulers and runtimes (Slurm, PBS, CUDA-Q, Qiskit Runtime) to quantum hardware. Writes the interfaces, workflow engines, and data-movement code that make hybrid quantum–classical jobs run reliably.

Typical employers include Quantinuum (advertised as "Advanced Software Engineer, Hybrid Quantum-HPC Orchestration") and other QPU and SDK companies. Expect a Python or C++ coding bar that is higher than for a pure admin role.

## Physics depth required: Working to Deep (for software design)

You need to understand what the software does to the quantum state, and how timing and noise affect workflow design.
